ELETool

Creador de Sprites (FNF)

Esta herramienta permite crear spritesheets y archivos XML para personajes de Friday Night Funkin'. Puedes subir tus frames, organizarlos automáticamente, renombrarlos y generar un ZIP listo para utilizar en tu juego. Fue pensado especialmente para usuarios de móvil, ya que en un teléfono puede ser un poco más complicado preparar sprites para el juego.

Instala ELETool en la pantalla de inicio para abrirlo como una aplicación.
⚠️ Para evitar errores, todos los frames de las secciones de animación deberían tener la misma resolución, tanto de ancho como de alto. Por ejemplo, si tus frames de Idle son 1024×1024 px, es recomendable que los frames de Left, Down, Up, Right y de las demás secciones de animación también sean 1024×1024 px. Si el ZIP no se quiere generar, tal vez se deba a que no todos los frames tienen la misma resolución.

Ayuda

Aquí encontrarás información sobre las funciones del creador de spritesheets.

¿Qué hace este programa?

Permite organizar imágenes, crear spritesheets automáticamente, renombrar frames y generar los archivos necesarios para usarlos en mods de Friday Night Funkin'.

Secciones con XML y renombrado

Las secciones Idle, Left, Down, Up y Right están pensadas para las poses de un personaje. Puedes subir varios frames, establecer un nombre base y renombrarlos automáticamente con números de cuatro dígitos.

Secciones de Spritesheet

Puedes agregar secciones adicionales para imágenes que solo necesiten convertirse en un spritesheet. Estas secciones no generan XML ni cambian los nombres originales de tus imágenes.

Distribución automática

El programa calcula automáticamente la distribución de filas y columnas según la cantidad de frames. No necesitas elegir manualmente el número de columnas.

Nombres de frames y paquete

El nombre del paquete se utiliza para los archivos principales generados. Los nombres de los frames normales se pueden generar automáticamente y se guardan en minúsculas.

¿Tus poses muestran las poses “miss” por instantes?

Si en el juego tus spritesheets cargan mal y algunas poses muestran sus poses “miss” por instantes, renombra todas las poses con una letra diferente a sus poses miss. Por ejemplo, si tienes Personajeleft y Personajemissleft, cambia Personajeleft a Personajeleftt, añadiendo una letra extra al final para evitar problemas.

Consejos

  • Usa imágenes con transparencia cuando tu personaje o elemento necesite un fondo transparente.
  • Revisa la vista previa y las estadísticas antes de generar el ZIP.
  • Si agregas una sección que ya no necesitas, puedes eliminarla desde esa misma sección.

Guía completa de ELETool

Esta guía explica para qué sirve cada herramienta y cómo usarla desde el teléfono o PC.

1. Creador principal
Sube los frames en Idle, Left, Down, Up y Right. Puedes agregar secciones XML adicionales para otras animaciones. Las secciones normales usan nombres y numeración de cuatro dígitos. Después revisa las vistas previas, escribe el nombre del paquete y genera el ZIP.
2. Creador de Spritesheet sin XML
Sirve para juntar imágenes en un PNG spritesheet sin crear XML. Conserva los nombres originales y calcula automáticamente la distribución.
3. Creador de iconos
Carga el icono neutral y el de derrota/perdiendo. ELETool los coloca en un spritesheet 2:1; por defecto 300×150 px, con cada icono ocupando 150×150 px.
4. Convertidor de imágenes
Carga una imagen y conviértela a PNG, JPG o WebP. El procesamiento se hace en el dispositivo.
5. Inspector y editor XML
Carga un XML, revisa si es válido, edita su contenido y descarga la versión modificada. Es útil para comprobar o corregir nombres y datos de SubTexture.
6. Cargar Spritesheet + XML para probar
Carga un PNG/WebP junto con su XML. ELETool detecta grupos de frames, intenta relacionarlos con Idle/Left/Down/Up/Right y permite asignar manualmente animaciones extra. Si eliges una pose extra, se importan todos los frames que comparten su nombre base.
7. Visor de Spritesheet
Muestra la hoja completa y, si cargas el XML, dibuja los límites y nombres de cada frame para comprobar que el atlas está bien organizado.
8. Visor de animaciones
Elige una sección y establece los FPS para reproducir sus frames en bucle. Sirve para detectar rápidamente frames faltantes o secuencias incorrectas.
9. Visor FNF por flechas
Idle se reproduce automáticamente. Las flechas reproducen Left, Down, Up y Right. Mantener una flecha puede repetir la pose rápidamente y las secciones extra aparecen como botones adicionales.
10. Probador de Sprites
Permite cargar hasta tres personajes con PNG/WebP + XML en una escena de pantalla completa. Selecciona qué personaje controlas, usa W/A/S/D o las flechas en PC, y los cuatro controles táctiles en móvil. Arrastra el personaje para moverlo y usa las cuatro esquinas del contorno para escalarlo. Las poses extra aparecen como controles adicionales. También puedes colocar un fondo.
11. Funciones generales
El selector de idioma cambia entre español e inglés. Vista previa del spritesheet permite revisar el resultado antes del ZIP. Borrar todo restaura el creador a su estado inicial después de confirmar. Instalar ELETool permite usar la PWA desde la pantalla de inicio cuando el navegador lo admite.
